隐私政策

更新日期：2026年10月14日　生效日期：2026年10月11日

「习惯本」重视您的隐私。请仔细阅读本政策，了解我们如何处理相关信息。

一、我们收集的信息

  1. 本地习惯数据：您创建的习惯名称、图标与颜色偏好、打卡记录、备注文字、提醒开关与提醒时间等，默认仅保存在您的设备本地。
  2. 通知权限：若您开启每日提醒，系统可能向您申请本地通知权限，用于在指定时间发送提醒。关闭提醒或撤销系统权限后，将不再发送相关通知。
  3. 统计分析信息：在您同意本政策后，我们可能通过第三方统计 SDK（友盟+）收集与 App 运行相关的设备与使用信息（如设备型号、系统版本、应用版本、启动与活跃等），用于改进产品体验。该等信息不包含您的习惯名称、打卡备注等内容。
  4. 本应用不要求注册账号，也不主动收集姓名、手机号、身份证号、精确位置、通讯录、相册等内容。
  5. 本应用当前不提供云同步或账号系统，不会将您的打卡内容上传到我们的服务器。

二、信息的使用

  1. 用于展示今日打卡、习惯管理、历史记录与热力图等核心功能。
  2. 用于在您授权后发送本地提醒通知。
  3. 用于统计 App 活跃与稳定性，以便优化功能与体验。
  4. 不会将您的本地打卡记录用于广告画像、个性化营销或出售给第三方。

三、信息的存储与保护

  1. 习惯与打卡相关记录主要存储于您的设备（如系统本地数据库 / SwiftData）。
  2. 统计分析相关数据由友盟+ 按其服务与安全能力进行处理，详见其隐私政策。
  3. 卸载应用或清除应用数据后，本地记录可能被删除且无法恢复。
  4. 请妥善保管您的设备；设备丢失、被他人使用或未设置锁屏，可能导致本地数据被查看。

四、第三方 SDK 与信息共享

除法律法规要求外，我们不会向第三方出售、出租您的本地使用记录。当前版本接入的第三方服务如下：

  1. 友盟+ SDK（UMCommon / UMDevice / UMAPM）
    运营方：友盟同欣（北京）科技有限公司
    用途：移动统计（U-App）与应用性能监控（U-APM），用于了解启动活跃、崩溃卡顿等，帮助改进产品
    收集信息类型：设备标识相关信息、设备与系统信息、应用使用与性能相关信息等（以 SDK 实际采集为准）
    收集方式：仅在您同意本《隐私政策》之后正式初始化并采集
    隐私政策：https://www.umeng.com/page/policy

本应用当前不接入第三方广告 SDK。

五、权限说明

  1. 通知：仅用于习惯提醒，可在系统设置中随时关闭。
  2. 本应用不强制索取与功能无关的权限；统计分析不依赖额外敏感权限申请。

六、未成年人保护

若您为未成年人，请在监护人指导下使用本应用。

七、政策更新

我们可能适时更新本政策，并通过应用内链接或本页面展示。更新后继续使用本应用，即视为您已知悉相关变更。
